Como ler o painel

Chance: calculada pelo modelo. Odd justa = 1 / chance: se a casa pagar acima dela, o cenario esta bem pago. Na pratica a casa quase sempre paga um pouco abaixo (a margem dela).

Toque num cenario para conferir a odd real. Use + combinada para montar uma combinada com quantos jogos quiser e depois Salvar aposta para acompanhar em Minhas apostas. Jogos que ja comecaram somem do painel.

Leitura organizada dos dados, nao garantia de resultado. Aposte so o que pode perder.
